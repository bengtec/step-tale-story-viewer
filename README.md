# Story paths

A static viewer for a step-tale `story.json`. Open a file in the browser, or load a public URL. The file is not uploaded.

Map shows every beat. Walk follows the thread without waiting on steps.

Host it with GitHub Pages from the `main` branch, folder `/`. A story on the public web can be linked as:

```text
https://<user>.github.io/<repo>/?url=https://raw.githubusercontent.com/<user>/<repo>/<ref>/story.json
```

https://bengtec.github.io/step-tale-story-viewer/

The URL must allow cross-origin reads. A file chosen on your computer does not need that.
